# 開発環境構築手順
## オンプレミス環境
### バックエンド構築
#### サーバーとして動かすための手順
1. Node.jsとPostgreSQLをPCにインストールする
2. /backendフォルダにcdコマンドで移動する
3. 「npm install」をターミナル上で実行して、NodeModulesをインストールする
4. .envファイルを作成する。中身は、DATABASE_URL="postgresql://user:passwoed@localhost/room_temperature_db"にする。
5. 「npx prisma migrate reset」をターミナル上で実行する
6. 「npx prisma generate」をターミナル上で実行する
7. 「npx prisma db seed」をターミナル上で実行して、DB内に初期データを入れる
8. VSCodeの拡張機能で「Database Client JDBC」を入れて、DBと接続してVSCode上でDBを確認できるようにする。
9. ターミナル上で「npm run dev」を実行して、サーバーを起動する
#### バックエンドのCURLコマンド入力
- Postmanから実行する
  - VSCodeの拡張機能「Postman」をインストールして、http://localhost:3000/measurement/air-pressure/get/per-monthのような形でコマンドを入力する
  - 室内履歴データのPOSTについては、以下のコマンドをコマンドプロンプトにて実行
    - curl -X POST http://localhost:3000/measurement/inside/post -H "Content-Type: application/json" -d "{\"device_id\":\"00:11:22:33:44:55\",\"inside_temperature\":25,\"inside_humidity\":55,\"inside_air_pressure\":1013,\"measurement_time\":\"2026-02-07 07:18:25.577\"}"
